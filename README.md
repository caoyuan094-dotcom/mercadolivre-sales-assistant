# 美客多销量助手

Chrome 扩展，用于在 Mercado Livre / Mercado Libre 搜索结果页显示商品的**累计销量档位**、**近30天公开销量或本机观察增量**、官方类目排名和人民币参考价，并把关键词搜索前 20 名自然结果导出为带图片的 Excel。

## 以图找同款

- 在巴西站搜索结果页点击“以图找同款”，选择 JPG、PNG 或 WebP 参考图。
- 插件在浏览器本机比较当前已加载商品的主图，显示相似度百分比，并按相似度从高到低重新排列。
- 参考图不会上传到第三方；最多比较当前页面前 80 个已加载自然商品。
- 对同图、轻微裁剪、换白底的同款最有效。不同拍摄角度、遮挡严重或主图完全不同的同款可能漏掉；该功能不是美客多官方全站图片搜索。

## 安装

1. 下载仓库源码并解压，或使用 Git 克隆仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的仓库文件夹。
5. 回到美客多搜索结果页并刷新一次。

macOS 用户也可以双击仓库中的 `安装美客多销量助手.command`，直接打开扩展管理页。

## 数据口径

- 插件读取美客多搜索卡片或公开商品页中的累计已售；`+1 mil`、`+10 mil` 等是档位下限，不是精确销量。
- 同一销量档位采用并列排名，再用官方类目排名、评分、评价数和平台原排序作为显示顺序参考，避免伪造精确名次。
- 近30天优先使用平台公开值；平台未公开时，插件从首次读取开始每天保留销量快照，显示观察天数，满30天后给出快照增量。
- 档位未变化只表示“公开档位未变化”，不代表最近30天销量为零，也不会用累计销量推算月销量。
- 广告不计入自然排名及前20名导出；同一目录商品下的不同卖家刊登仍按页面位置分别排名。
- 排序只作用于当前已加载的搜索结果；滚动加载更多商品后会继续读取。
- 排序会自动识别新版页面的商品外层容器；美客多动态刷新列表后，插件会维持当前选择，并在工具栏显示实际重新排列的商品数量。
- 商品详情使用4个读取任务并行等待响应，但后台仍限制为每500ms最多启动一个新请求；销量缓存12小时，快照保留40天，在提速和平台风控之间保持边界。

## 汇率换算

- 根据站点自动识别 BRL、MXN、ARS、CLP、COP、PEN，通用站点可识别 US$。
- 在商品原价旁显示“约 ¥…”人民币参考价，不替换平台原价。
- 使用 Frankfurter 的公开参考汇率，无需 API Key；汇率缓存 12 小时，可在插件弹窗手动刷新。
- 汇率接口不可用时优先使用上次缓存；没有缓存时只暂停人民币显示，不影响销量读取和排序。

## 一键导出前 20 名

- 在关键词搜索结果页点击工具栏“导出前20名”，或点击插件图标后选择“导出当前关键词前20名”。
- 导出顺序跟随插件当前选中的排序；先点击累计销量、近30天、官方类目或平台原排序，再导出对应排名的前20名。
- Excel 第一页为参考《巴西婴儿车价格参考表》设计的黄色“前20名榜单”，第一列固定显示本次导出排名1-20；第二页保留平台排名、自然排名、累计/近30天排名、图片、名称、价格、销量口径、官方类目排名、评价、链接、数据时间和刊登ID。
- 人民币列使用工作簿公式引用导出时汇率；顶部同时记录关键词、导出时间、汇率日期、来源页面和销量口径。
- 导出会等待前 20 个商品的销量读取；个别图片或销量无法取得时仍会保留该商品行并明确标注。

## 全部页面销量榜单

- 点击“读取全部页”后，插件会沿美客多搜索结果的“下一页”自动遍历到最后一页，汇总并去重所有自然商品。
- 如果美客多新版页面不再暴露可识别的“下一页”按钮，插件会自动按巴西站每页结果偏移地址继续读取，直到后续页面不再出现新商品。
- 汇总完成后继续按限速队列读取每个商品详情页的公开销量，并生成可滚动的全量销量榜单。
- 榜单顶部显示页面标称结果数、实际发现数、销量成功数、未公开数和失败数；没有公开销量的商品不再显示虚假的销量排名。
- 全量读取完成后，“导出前20名”会从全部页面的数据中选取当前排序的前20名，不再只使用当前页。
- 商品越多耗时越长。插件每900ms最多读取一个搜索结果页，商品详情仍按每500ms最多启动一个请求，避免瞬间大量访问。
- 美客多要求登录或账号验证时，全量读取会停止并明确提示；插件不会绕过登录、验证码或平台风控。

## 支持站点

巴西、墨西哥、阿根廷、智利、哥伦比亚、秘鲁及 `mercadolibre.com` 主域名。
